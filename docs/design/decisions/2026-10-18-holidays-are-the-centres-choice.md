# Public holidays are the centre's own closed days; India's list is an import
18 Oct 2026, audit F-hol-1. Decided by the maintainer.
A holiday is a closed day only once recorded in the platform. The app offers India's main gazetted days to import for fast onboarding (HolidaysSheet); the admin ticks which the centre observes and can edit later. Nothing is closed by default for a real centre. The audit saw 21 closed days only because the demo seed imports them.
