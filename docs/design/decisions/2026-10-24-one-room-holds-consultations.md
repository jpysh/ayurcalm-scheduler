# A centre that keeps no consultation room in Get started sees residents in its first room
24 Oct 2026, #1140, decided by Claude, to confirm.

When the rooms ticked in Get started include none with what a consultation needs (the example's BP monitor and examination bed), the first ticked room is given those needs. A one-room centre sees new residents in the room it has; without this, every resident arriving after Get started had no consultation and the message blamed a busy day. Left out: asking which room, which would be one more question in a three-screen wizard; the room's needs can be changed in Rooms.
