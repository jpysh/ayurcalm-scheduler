# A group's shared programme is a programme event for the group (27 Oct)

Decided in the unattended stays session for #1196 part 3, on the maintainer's 26 Oct brief ("yoga at 7, Abhyanga in turns, with individual treatments on top").

- The shared part (yoga at 7) is an event with the group's name, every day of the group's dates, added on the group's sheet. It belongs to whoever is in the group, so a guest added later from the organiser's list has it too.
- It prints in each guest's own row of the day sheet, not in the line for everyone. The kitchen sheet ignores it.
- Treatments stay per guest, booked as usual ("Abhyanga in turns" is each guest's own Abhyanga). The day check names a treatment that runs through a required part of the group's programme, for that group's guests only. It is a note, not a refusal, as for any required event.
- Moving the group's dates moves its programme too.
