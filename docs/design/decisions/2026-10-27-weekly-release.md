# Centres update weekly, on the walked version (#1178)

Decided 27 Oct by the maintainer. The nightly 21:00 update is gone. Centres update once a week,
Wednesday in the 20:00 hour India time, and only to the version Tuesday's walk approved
(`~/ruta-data/release-ok`, written by the walk task in `hosting/tuesday-walk.md`). No approval,
because the walk found something red or did not run, means no update that week, and the morning
note says so. `touch ~/ruta-data/update-now` stays for a same-day fix when a centre cannot work;
Claude uses it only when the maintainer asks. Rollback is the next part.
