# Print opens one sheet, not a note (21 Oct, #1030)

**Decided by the maintainer, 21 Oct.** Print in the Menu opens a bottom sheet:

1. When the day has problems, a top line "⚠ N problems on the day · Fix first" that opens them.
2. **Print all sheets** as the main button: one PDF with the Patient, Therapist, Doctor, Kitchen and (where the centre has them) Guest rooms sheets, each starting on its own page.
3. The sheets as rows, each printing just that one.

No note after printing. Problems such as "Bhavna not in" are marked on the printed sheet itself (second part, its own PR).

**Why:** the old note carried five buttons for ten seconds and printed only the patient sheet first. All five sheets now take 3 taps instead of 6.
