# A bad release goes back on its own (#1178)

Decided 27 Oct, from the release plan the maintainer set on 26 Oct ("automatic app-only rollback").
If a centre does not come up after Wednesday's release, every centre the release already touched is
rebuilt on the version it ran before, and the alert says so. Only the app goes back: the data stays,
and the backup taken just before each centre's update is there if the data needs restoring too.
A release that comes up but is wrong in use goes back with `touch ~/ruta-data/rollback-now`, which the
maintainer asks Claude to do; that version is then not shipped again until the walk approves a newer one.
