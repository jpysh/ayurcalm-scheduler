# Decisions

One file per decision, named `YYYY-MM-DD-slug.md`, written in the PR that makes it:

    # <the decision in one line>
    Date, issue/PR, "decided by Claude, to confirm" or "decided by the maintainer".
    What was decided, and why, in a few sentences. What was left out.

Why not a line in `../DESIGN.md`: every PR appended to its last line, so parallel
PRs conflicted on it again and again. `../DESIGN.md` keeps the rules (type scale,
kit, checklist) and the decisions up to 9 Oct 2026; later ones live here.
