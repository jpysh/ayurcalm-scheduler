# The morning streak sits under Print (27 Oct, #1305)

"Printed 3 mornings in a row" is the facts line of *Print the day's sheets* in the menu, shown from a run of two. Printing is the morning job, so it is said back where that job starts. It counts back from the centre's today, and a morning not yet printed does not break the run. It adds no row and no tap.
