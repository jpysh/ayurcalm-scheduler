# The course line names the days the server would book

13 Oct 2026, #792, decided by Claude.

Before Book, the course sheet asks the scheduler for a preview and names the days it returns, not the start day plus the count. A day the resident is away or the therapist or room is busy is skipped, so the real course can end later; the admin sees that before booking, and sees "only N of M days fit" instead of a refusal after. Cost: one extra call each time the day, time, therapist, room or count changes. Left out: listing each skipped day by name.
