# The home-screen offer is one toast after the first sheet (27 Oct, #1310)

After the first printed sheet on a touch phone, one toast says how to add Ruta to the home screen (Safari: Share, Add to Home Screen; Chrome: ⋮, Add to Home screen). It stays until OK, since the sheet opens in another tab. Once per device, never when already opened from the home screen. No install banner or manifest: index.html is the public access session's, and both browsers add a shortcut without one.
